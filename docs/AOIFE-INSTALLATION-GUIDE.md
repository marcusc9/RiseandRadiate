# Rise & Radiate website upgrade

Keep the attached `rise-and-radiate-rescue.zip` file zipped. Do not open or extract it.

## Before you begin

1. Sign in to WordPress with an Administrator account.
2. Confirm that **Plugins → Add New Plugin → Upload Plugin** is available.
3. Take a full website backup through the hosting account.

If **Upload Plugin** is not available because the site is on the free WordPress.com plan, the site must first move to a paid WordPress.com plan or ordinary WordPress hosting.

## Install the upgrade

1. Open **Plugins → Add New Plugin → Upload Plugin**.
2. Choose `rise-and-radiate-rescue.zip`.
3. Select **Install Now**.
4. When WordPress asks, select **Activate Plugin**.
5. Open **Tools → Rise & Radiate Rescue** and confirm that the installation report is complete.

## Check the website

Open the public website in a private browser window and check Home, About, Parent Support, Organisations, and Contact. Also check the mobile menu and send one test message through the contact form.

## Making simple changes later

Use **Pages** for normal wording changes. Preview before selecting **Update**. If anything looks wrong, stop and use the page’s **Revisions** panel or contact Marcus.
