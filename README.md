# Rise & Radiate website rescue

This repository contains a focused WordPress upgrade for [riseandradiate.net](https://riseandradiate.net/).

The upgrade is packaged as the **Rise & Radiate Rescue** plugin. Activating it:

- replaces the leftover template identity and logo;
- cleans the About and Contact page URLs;
- restores the missing Teen Coaching and Adult Coaching pages;
- repairs the matching navigation links and legacy URLs;
- removes duplicated About copy;
- repairs the homepage Learn More link;
- makes contact details clickable;
- adds a homepage description for search engines when no SEO plugin manages it;
- hides the placeholder Facebook destination;
- applies a restrained, responsive visual refresh; and
- creates an unpublished privacy-notice draft for review.

Original page content and global settings are recorded before the first change. WordPress revisions are also created before existing page content is replaced.

## Deliverable

The installable ZIP is generated in `dist/rise-and-radiate-rescue.zip`.

See [docs/INSTALLATION.md](docs/INSTALLATION.md) for installation and verification, and [docs/AOIFE-QUICK-EDITS.md](docs/AOIFE-QUICK-EDITS.md) for the minimal editing handover.
